Este portfolio (nelthor.qzz.io) se construyó con flujos de trabajo de desarrollo agéntico — no como un gimmick, sino como una demostración de cómo funciona la ingeniería aumentada por IA en la práctica.

## El Stack

Next.js 15 static export, Tailwind CSS 4, TypeScript. Deployado a GitHub Pages con un dominio gratuito de DigitalPlat (qzz.io) y DNS alojado en FreeDNS (afraid.org). Herramientas estándar, setup estándar — pero el proceso fue todo menos estándar.

## Cómo Se Construyó

Cada feature siguió el mismo ciclo:

1. **Planificar** — `/project-foundation` definió la spec (PRD, SRS, diseño)
2. **Refinar** — `/product-management` estructuró el backlog en épicas y stories
3. **Implementar** — `/sprint-development` llevó cada story a través de código, review y deploy
4. **Verificar** — Los health checks (`bun run health:check`) validaron assets, frescura y consistencia

La IA nunca trabajó sola. Proponía, yo aprobaba. Codeaba, yo revisaba. Deployeaba, yo verificaba.

## El Enfoque de Agentic QA

Como ingeniero de QA, encaré esto de la misma manera que encaro cualquier entregable: definir criterios de aceptación, testear mientras construís, verificar antes de shipping. Las skills de IA manejaban la ejecución — yo manejaba el criterio.

La misma disciplina que detecta bugs en producción también detecta layouts rotos, contenido desactualizado y branding inconsistente. Calidad es calidad, ya sea que el código esté escrito a mano o generado por IA.

## Qué Demuestra

Este portfolio demuestra que el desarrollo agéntico no se trata de reemplazar ingenieros. Se trata de correr el trabajo de **escribir código** a **dirigir la calidad**. La IA maneja la mecánica; el ingeniero maneja la intención.

Eso es lo que significa Agentic QA Engineer para mí.
